# Project evidence checklist

For each repeatable lab:

- State the objective, environment, authorization, date, and tool versions.
- Include original commands or queries and sanitized output.
- Separate observed findings from expected results and hypotheses.
- Explain one limitation and one practical security implication.
- Remove credentials, tokens, private hostnames, personal data, and employer information.
- Use only material you have permission to publish; write your own explanations of course exercises.
